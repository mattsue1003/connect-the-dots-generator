# connect-the-dots-generator
連連看生成器

用瀏覽器打開 `index.html` 就能用，不需要安裝任何東西。

- 50 種可愛圖案：動物 18、自然 10、食物 5、生活 14、形狀 3，多數有眼睛與腮紅等細節
- 數字會自動避開圖案細節與其他數字，不會壓在眼睛或線條上
- 點數可調（10–150），轉角一定會放點，連出來的形狀不會走樣
- 數字可以 1、2、3 數，也可以 2、5、10 個一數，或用英文字母
- 可切換順時針／逆時針、換起點、調整字和點的大小
- 學習單模式：A4 版面，含姓名、日期、猜一猜、給自己打星星和塗色建議；四種花邊（星星、愛心、小花、簡約）；可列印或下載 PNG／SVG
- 線上玩模式：依序點擊數字連線，完成後圖案自動上色並灑彩紙；停太久會自動提示下一個點
