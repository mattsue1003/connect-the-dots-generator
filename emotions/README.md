# 心情小怪獸：幼兒情緒辨識與表達小遊戲

給 3 歲左右、還不太認字的孩子使用。全程**語音引導**、**大圖大按鈕**，孩子不用認字也能自己玩。

- 適合年齡：約 2–5 歲
- 使用裝置：手機、平板、電腦的瀏覽器（建議 Chrome 或 Safari）
- 不用安裝、不用登入、不收集任何資料

---

## 一、四個活動

建議依序進行，每次 5–10 分鐘就好。

### 1. 認識表情 😊

- 五種基本情緒：**開心、難過、生氣、害怕、驚訝**
- 點一張臉，語音會說明這個表情長什麼樣子，例如：
  > 這是生氣。生氣的時候，眉毛皺起來，身體熱熱的。
- 請孩子跟著做出同樣的表情，大人也一起做、一起照鏡子。

### 2. 找一找 🔍

- 語音問：「哪一個是生氣的臉？」孩子從圖片中選出來。
- 一開始 2 選 1，連續答對 3 次後變成 3 選 1。
- 答對有星星和音效；答錯圖片只會輕輕搖一下，語音請孩子再試一次，不扣分。

### 3. 發生什麼事？ 📖

10 個生活情境，孩子聽完故事後選出「他會覺得怎麼樣」：

| 情境 | 可以的答案 | 示範說法 |
|---|---|---|
| 冰淇淋掉到地上了 | 難過 | 我覺得難過，因為冰淇淋掉了。 |
| 辛苦疊好的積木倒了 | 難過、生氣 | 我覺得生氣，因為積木倒了。我可以說：請幫我，我們再疊一次。 |
| 收到生日禮物 | 開心、驚訝 | 我覺得開心，因為收到禮物。 |
| 外面打雷，好大聲 | 害怕、驚訝 | 我覺得害怕，因為打雷很大聲。我可以說：抱抱我。 |
| 玩具被別人拿走了 | 生氣、難過 | 我覺得生氣，因為玩具被拿走了。我可以說：還給我，我還在玩。 |
| 氣球突然破掉了 | 驚訝、害怕 | 我覺得驚訝，因為氣球突然破掉了。 |
| 去公園溜滑梯 | 開心 | 我覺得開心，因為可以溜滑梯。 |
| 在商場找不到媽媽 | 害怕、難過 | 我覺得害怕，因為找不到媽媽。我可以說：媽媽，你在哪裡？ |
| 鞋子一直穿不上去 | 生氣、難過 | 我覺得生氣，因為鞋子穿不上去。我可以說：請幫我。 |
| 門一打開，小狗跳出來 | 驚訝、開心、害怕 | 我覺得驚訝，因為小狗突然跳出來。 |

> 有些情境不只一個答案，每個人的感覺可以不一樣。重點是讓孩子聽到並跟著說：**「我覺得＿＿，因為＿＿。」**

### 4. 我的心情 💗

- 孩子點一張臉，告訴大人「我現在覺得怎麼樣」，可以當成每天的心情打卡。
- 選了**難過、生氣、害怕**，會出現 6 個冷靜小方法：

| 方法 | 做法 |
|---|---|
| 🎈 吹氣球 | 氣球跟著變大變小，用鼻子吸氣、嘴巴吐氣，做 3 次 |
| 🖐️ 數到 5 | 跟著語音慢慢數 1、2、3、4、5 |
| 🤗 抱抱 | 去找媽媽說「抱抱我」，抱緊緊數到 5 |
| 🗣️ 說出來 | 跟著說「我覺得＿＿，因為＿＿」 |
| 🙋 請幫我 | 做不到的時候不用哭，練習說「請幫我」 |
| 🧸 抱玩偶 | 抱最喜歡的玩偶，摸摸它的頭 |

- 做完後會再問一次「現在感覺怎麼樣？」。孩子變開心時，語音會稱讚他用了好方法。

## 二、給家長：孩子遇到小挫折就哭的時候

1. **先接住情緒，再處理事情**
   先幫孩子說出情緒的名字：「你很生氣，因為積木倒了，對不對？」
2. **平常先練習冷靜方法**
   吹氣球（深呼吸）、數到 5、抱抱、抱玩偶。平靜的時候練熟，哭的時候才用得出來。
3. **教替代說法**
   把哭換成一句話：「請幫我」、「我需要休息」、「我很生氣」。孩子說出來時立刻稱讚。
4. **冷靜後再回頭**
   「剛剛你很難過，後來吹氣球就好多了！」幫孩子記住成功的經驗。

## 三、換成自己的圖片

程式內建畫好的表情圖，也可以換成 ChatGPT 生成的插畫，或**孩子自己做表情的照片**（對 3 歲孩子最有效）。

**方法 A：在程式裡直接上傳（最簡單）**

1. 首頁下方按「🖼️ 換圖片（家長）」。
2. 按「開啟 ChatGPT」，先按「📋 複製共同風格」貼上送出。
3. 每一項按「📋 複製 Prompt」，貼到同一個 ChatGPT 對話生圖。
4. 圖片生好後儲存，回到程式按「⬆️ 上傳」。按「↩️ 還原」可以改回內建圖。

> 上傳的圖片只存在那台裝置的瀏覽器裡。建議直接在孩子要用的平板上傳。

**方法 B：放進資料夾**

把圖片放進 `emotions/images/`，檔名照 [PROMPTS.md](PROMPTS.md) 的命名（例如 `happy.png`、`scene-blocks.png`）。

完整的 ChatGPT 生圖 Prompt 請見 **[PROMPTS.md](PROMPTS.md)**。
