# ChatGPT 生圖 Prompt（心情小怪獸）

把下面的 Prompt 貼到 ChatGPT（需能生圖的版本）。**先貼「共同風格」，再一張一張貼個別 Prompt**，同一個對話裡生完，角色才會長得一樣。

生好後下載，改成表格裡的檔名，放進 `emotions/images/`，網頁會自動換成你的圖。

## 0. 共同風格（第一句先貼）

```
接下來我要請你幫我畫一系列給 3 歲幼兒看的情緒教學圖卡。請全部維持同一個風格：
- 主角是一個圓圓的、可愛的小男孩（約 3 歲，短髮，穿黃色上衣），每張都是同一個人
- 扁平插畫、粗黑外框、明亮飽和的顏色、背景簡單乾淨（白色或淺色）
- 表情要誇張、非常容易辨認，臉部占畫面大部分
- 圖片裡不要有任何文字、字母或數字
- 正方形 1:1
請先回答「好」，我再一張一張告訴你要畫什麼。
```

## 1. 五種表情（正方形，臉部特寫）

| 檔名 | Prompt |
|---|---|
| `happy.png` | 畫主角「開心」的臉部特寫：大大的笑容露出牙齒、眼睛笑成彎彎的月亮、臉頰紅紅的，背景淡黃色。 |
| `sad.png` | 畫主角「難過」的臉部特寫：嘴角往下、眉毛內側往上、眼睛含淚、一顆眼淚流下來，背景淡藍色。 |
| `angry.png` | 畫主角「生氣」的臉部特寫：眉毛往下皺成 V 字、嘴巴緊閉往下、臉紅紅的、雙手握拳，背景淡紅色。 |
| `scared.png` | 畫主角「害怕」的臉部特寫：眼睛睜很大、眉毛往上、嘴巴微開發抖、雙手抱著自己、肩膀縮起來，背景淡紫色。 |
| `surprised.png` | 畫主角「驚訝」的臉部特寫：眼睛睜很大、眉毛抬很高、嘴巴張成圓圓的 O 形、雙手張開，背景淡橘色。 |

## 2. 情境圖（4:3 橫式，畫出發生什麼事，主角表情先畫「平平的」或背對）

> 情境圖裡主角的表情請畫得**不明顯**（或只看到背影），讓孩子自己猜心情。每張都加一句：「請畫成 4:3 橫式，主角表情不要太明顯，讓小朋友猜。」

| 檔名 | Prompt |
|---|---|
| `scene-ice.png` | 主角手上拿著空的甜筒，冰淇淋球掉在地上融化。 |
| `scene-blocks.png` | 主角面前一座疊高的積木塔倒下來，積木散落一地。 |
| `scene-gift.png` | 主角面前有一個綁著蝴蝶結的大禮物盒和生日蛋糕。 |
| `scene-thunder.png` | 晚上窗外下大雨、閃電打雷，主角在房間裡看著窗戶。 |
| `scene-toy.png` | 另一個小朋友從主角手中拿走他的玩具熊。 |
| `scene-balloon.png` | 主角手上的氣球突然爆破，碎片飛散，畫出「砰」的爆炸線條（不要文字）。 |
| `scene-park.png` | 晴天的公園，主角在溜滑梯上準備溜下來。 |

| `scene-shoes.png` | 主角坐在地上，用力想把鞋子穿上去，但穿不進去。 |
| `scene-puppy.png` | 主角打開家門，一隻小狗突然跳出來。 |

## 3. 小技巧

- 生出來的圖如果有文字，回覆「請把圖片裡的文字全部拿掉」。
- 角色跑掉時，回覆「請和第一張的小男孩長得一模一樣」。
- 最有效的還是**孩子自己的表情照片**：請孩子對著鏡頭做開心、難過、生氣、害怕、驚訝的臉，照片照上面檔名放進 `images/` 就可以。
