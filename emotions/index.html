怎麼玩

  • 每個畫面都會說話，孩子不用認字。按綠色 🔊 可以再聽一次。
  • 建議順序：認識表情 → 找一找 → 發生什麼事 → 我的心情。每次 5–10 分鐘就好。
  • 「認識表情」點一張臉，請孩子跟著做出同樣的表情，大人也一起做、一起照鏡子。
  • 「找一找」答對 3 次會變成 3 個選項。答錯只會搖一搖，不會扣分。
  • 「發生什麼事」有些情境不只一個答案（積木倒了可以難過也可以生氣），重點是讓孩子聽到並跟著說「我覺得＿＿，因為＿＿」。
  • 「我的心情」可以當成每天的心情打卡；選了難過、生氣、害怕時，會出現冷靜小方法。

遇到小挫折就哭的時候

  • 先接住情緒，再處理事情：「你很生氣，因為積木倒了，對不對？」先幫孩子說出情緒的名字。
  • 平常先練習冷靜方法：吹氣球（深呼吸）、數到 5、抱抱、抱玩偶。平靜時練熟，哭的時候才用得出來。
  • 教替代說法：把哭換成一句話——「請幫我」、「我需要休息」、「我很生氣」。孩子說出來時立刻稱讚。
  • 冷靜後再回頭：「剛剛你很難過，後來吹氣球就好多了！」幫孩子記住成功的經驗。

換成自己的圖片

  • 最簡單：首頁下方「🖼️ 換圖片」，可一鍵複製 ChatGPT Prompt，生好圖直接上傳。
  • 或把圖片放在這個網頁旁邊的 images/ 資料夾，檔名照 PROMPTS.md 列的命名（例如 happy.png、scene-ice.png），網頁會自動換成那張圖；沒有圖就用內建畫好的臉。
  • 也可以用孩子自己的表情照片（拍下孩子做開心、生氣的臉），對 3 歲孩子最有效。
